## 自动视频合成与清理验收

- 默认 2 秒拍 100 张，结束后应出现合成、校验、清理进度；结果为 1920×1080 MP4，默认优先 H.265，30fps，约 3.33 秒。
- 必须实际播放全片，核对开始、中间、末尾画面、颜色、拍摄方向和完整画面；metadata 的 video_frame_count 为 100，original_photos_deleted 为 true，项目 JPEG 数为 0。
- 拍摄中手动停止：至少 2 张才合成；只有 0/1 张时不删除原片。正常单张和倒计时拍照仍保存 JPEG。
- 关闭自动合成：没有 MP4，JPEG 全部保留。仅取消删除原片：MP4 和 JPEG 同时保留。
- 合成或校验中点击取消，模拟编码器失败、存储不足、损坏 JPEG：显示错误，原片全部保留，不导出临时视频。
- 合成中锁屏、回桌面、重新打开：通知和页面进度正常，无法重复开新任务；成功后可通过分享直接保存 MP4。
- 模拟视频已验证后清理失败：MP4 保留，未清理 JPEG 保留；元数据 remaining_original_count 可追踪剩余照片。
- 新增单元测试不执行 Android 硬件编解码器；当前没有连接 PRO-I，以上视频验收尚未执行。

## 编码选择真机验收（尚未执行）

- 自动模式检测并优先使用 H.265；核对 MP4 实际轨道 MIME 为 video/hevc，以及 metadata 编码、码率和 fallback 值。
- 切换节省空间、标准、高画质，分别合成同一场景，比较真实文件大小及播放画质；不以目标码率当作真实体积或等画质证据。
- 选择 H.264 后确保实际轨道 video/avc，不切换 H.265。
- H.265 不支持或编码/校验失败时回退 H.264，通知显示回退，最终 metadata 为实际成功格式。
- Android 14+ 且检测到支持当前设置的 AV1 硬件编码器时才可选择 AV1；其他设备选项禁用。实际输出 video/av01，解码校验通过后才清理 JPEG。
- 任一格式全部尝试失败或用户取消：保留原片，不留下可导出的临时 MP4。

## 分辨率与帧率验收（尚未执行）

- 对 720p、1080p、4K 与 24/25/30/60fps 各组合检查设备检测结果；不支持时开始按钮禁用，关闭自动合成后仍可拍照。
- 重复点击已选中的分辨率、帧率和画质，编码能力显示及开始按钮不应一直停留在检测中。
- 合成 120 张照片：24fps 约5秒、25fps 约4.8秒、30fps 约4秒、60fps 约2秒；逐帧检查无重复或漏帧。
- 核对视频实际轨道宽高、时间戳、EXIF方向及全部内容，metadata 中 requested_video_resolution、requested_video_fps 与最终 video_resolution、video_fps 一致。
- 4K/60fps 合成时记录内存、耗时及温度，不能以编码器宣称支持代替完整运行证明。
- 编码失败回退后，输出宽高和帧率仍须保持所选值；若全失败或用户取消，原始照片保留。
