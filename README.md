# Xperia Timelapse 0.5.8

Sony Xperia PRO-I 专属延时摄影 Android MVP。Kotlin、Jetpack Compose、CameraX + Camera2Interop，Android 10 起可运行。

## 已实现

- 相机权限与拒绝提示、实时预览；按传感器尺寸及像素数优先选后置主摄，能力页可手动选择其他公开镜头。
- 即时单张、3/5/10 秒及自定义倒计时。
- 默认每 2 秒拍摄 100 张；支持 1～3600 秒间隔、1～100000 张或 1～1440 分钟时长。
- 开始、暂停、继续、停止，进度、下一张时间、预计结束时间、估算存储。
- 单调时钟调度，包含拍摄与落盘耗时补偿；超时跳过错过的拍摄时点，不连续补拍；失败最多尝试 3 次。
- 服务持有 CameraX 生命周期，拍摄期间相机前台服务、通知停止按钮、CPU WakeLock；停止后释放资源。
- 能力检测包括硬件等级、传感器尺寸、快门/ISO范围、对焦、AE/AWB锁、JPEG/RAW/预览分辨率及帧率、防抖、高速视频尺寸。
- 开始前读取测光结果，支持设备上冻结快门与 ISO，或回退 AE 锁；固定当前对焦距离、锁定 AWB。实际启用情况写入元数据。
- 独立项目目录、JPEG顺序编号、元数据逐帧更新、错误日志、100 MB 存储保护；结束后 ZIP 分享导出。
- 延时拍摄结束后自动合成视频并保存到手机相册，默认成功后删除原始照片。正常完成或手动停止后，至少有 2 张照片时合成 可选 720p / 1080p / 4K、24 / 25 / 30 / 60fps MP4，默认 1080p / 30fps，优先 H.265；单张拍照保留照片。
- 原生 MediaCodec + MediaMuxer 编码，每次只处理一张图片，按 EXIF 方向旋转并保留完整画面（必要时补黑边），无音频。
- 合成进度和逐帧解码校验进度显示在页面及通知中。仅在全片解码帧数与原始照片数一致、视频写入成功、验证信息保存后删除该项目的原始 JPEG；失败或取消合成保留照片。
- 可取消合成或取消删除原片；完成后已自动保存到相册，仍可分享 MP4，或 ZIP 导出视频和元数据。

## 构建和安装

需要 JDK 17、Android SDK 34。Android Studio 打开本目录，配置 SDK 后同步即可。

```sh
./gradlew testDebugUnitTest assembleDebug lintDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

使用 JDK 17，可通过 `JAVA_HOME` 指定安装路径。`local.properties` 仅在本机配置，不应提交。

## 使用

1. 允许相机权限，Android 13+ 建议允许通知；等待取景画面出现。
2. 主界面选择拍照、定时或延时，点圆形快门开始。默认延时为每 2 秒拍 100 张。
3. 快门下方的设置入口进入拍摄设置，配置间隔、结束方式、倒计时，以及曝光、对焦、白平衡锁定。冻结的是预览测量值，暂不提供手动输入 ISO/快门/色温。
4. 必须从可见页面启动拍摄，再锁屏或切后台。通知中可停止，应用中可暂停与继续。
5. 视频输出菜单配置分辨率、帧率、编码和原片清理。等待合成和校验完成，从快门下方文件入口或菜单里的拍摄结果导出 MP4 视频或项目 ZIP；默认清理原片是永久删除。取消勾选“视频校验成功后删除原始照片”可保留原片。

照片位置是应用外部专属目录 `Android/data/com.xperia.timelapse/files/Pictures/XperiaTimelapse/<项目>/`，外部存储不可用时回退内部目录。目录在拍摄期间包含 `frame_000001.jpg`、`metadata.json`、`capture.log`（发生重试时）。自动合成后新增 `preview.mp4`，默认删除原始 JPEG，保留视频、元数据及日志。卸载会删除项目，请先导出。主界面文件入口打开手机相册；设置中的项目列表可查看本机历史项目、分享视频或导出 ZIP，重启应用后也可查看。

## 架构与边界

相机在 `LifecycleService` 中绑定；Activity 只提供可更换的预览 Surface 和控制页面。调度器只调用序列拍摄回调，存储独立负责落盘。没有使用 WorkManager 做秒级计时，因为此场景需要正在运行的相机服务和精确间隔。

服务使用 START_NOT_STICKY；进程被系统终止后不从后台擅自重开相机。已落盘 JPEG 与上一次原子写入的元数据保留，若元数据状态仍为 running，可检查文件数判断中断位置。锁屏相机访问受 Android 和 Sony 驱动/温控策略影响，前台服务及 WakeLock 不构成真机稳定性保证。

暂停期间保留相机与锁定参数；时长限制按实际运行时间计算，暂停时间不计入。停止会等待当前照片保存完毕再结束，因此不是立即中断文件写入。

白平衡冻结使用 AWB 锁，不伪造色温数值；对焦数值单位为屈光度。设备不支持的锁定不会强行写入 CaptureRequest，metadata 中对应布尔值为 false。高帧率与 RAW 目前仅检测，不拍摄。

后续阶段为手动参数输入、RAW、热管理和历史项目管理。此版不请求麦克风或广泛存储权限。

Android 相机前台服务官方限制见 [Foreground service types](https://developer.android.com/develop/background-work/services/fgs/service-types)。

## 验证

56 项自动测试覆盖 YUV 色彩和编解码平面布局、未验证视频不删除、空视频不删除、只删除本项目编号照片，以及拍摄耗时补偿、错过时点处理、倒计时停止、失败重试、时长结束、暂停恢复、持续失败终止和配置校验。真机验收步骤见 [docs/device-validation.md](docs/device-validation.md)。

合成阶段关闭相机，将前台服务切换为 dataSync 进行本地文件处理，并保持 CPU 唤醒，分类依据 [Android 前台服务类型文档](https://developer.android.com/develop/background-work/services/fgs/service-types)。PRO-I 硬件 H.265 的 1080p/30fps 短任务已通过全片解码；其他组合和长时间拍摄仍需继续验收。进程在合成或清理时被强制终止不会自动恢复，原始照片可能仍部分保留，已发布的通过校验的视频和 metadata 可用于恢复。

## 编码与压缩选项

设置中可选择自动（优先 H.265）、H.265、H.264 和本机可用时的 AV1。运行时检查所选分辨率、帧率、当前码率和 YUV 输入支持，优先选择硬件编码器；AV1 只开放 Android 14+ 的硬件编码，避免手机上软件 AV1 的耗时。MP4 的 AV1 封装支持从 SDK 34 开始，依据 [MediaMuxer 文档](https://developer.android.com/reference/android/media/MediaMuxer)。

以下目标码率以 1080p/30fps 为基准。

| 格式 | 节省空间 | 标准 | 高画质 |
| --- | --- | --- | --- |
| H.265 | 2 Mbps | 4 Mbps | 8 Mbps |
| H.264 | 4 Mbps | 8 Mbps | 12 Mbps |
| AV1 | 1.5 Mbps | 3 Mbps | 6 Mbps |

这些值是输出目标码率，实际体积和画质取决于编码器与画面。默认 H.265 目标码率为上一版 H.264 的一半，没有保证两者画质相同。节省空间档会降低画质。

自动/H.265 模式会按 H.265 → H.264 尝试；显式 H.264 只使用 H.264；AV1 模式按 AV1 → H.265 → H.264 尝试。编码或校验失败也会尝试后续格式，取消时立即结束并保留原片。界面和通知显示正在使用的编码，完成页面显示实际编码和码率；metadata 记录实际 MIME、编码器、码率、是否回退。

设备支持解码不代表存在可用编码器；实际 HEVC/AV1 支持以本机检测与真实合成为准。原片仍只在输出 MIME、分辨率和全片解码帧数校验通过且验证元数据写入后清理。

## 分辨率与帧率

视频输出分辨率为 1280×720、1920×1080 或 3840×2160；成片帧率为 24、25、30 或 60fps。默认值保持 1080p / 30fps。相机拍照分辨率与拍摄间隔不受这个设置影响，合成时按输出大小缩放并保留完整照片画面。

码率按输出像素数及帧率相对于 1080p/30fps 的比例调整，最低 0.5 Mbps。例如标准 H.265 在 4K/30fps 时目标为 16 Mbps，在 4K/60fps 时目标为 32 Mbps。成片时长约为照片张数 / 输出帧率，空间估算使用对应目标码率；实际体积和画质仍需实测。

修改分辨率、帧率或画质时重新检测本机编码器。在没有可用编码器时禁止开始自动合成拍摄，并提示用户调整设置；单张拍照模式仍可拍摄照片。编码回退保持用户所选分辨率和帧率，不悄悄降低输出规格。全部格式失败则保留照片。

生成视频后核对实际轨道分辨率、编码格式、逐帧显示时间戳以及完整解码帧数，再发布和清理原片。metadata 记录请求及最终输出规格，完成页面显示输出分辨率和帧率。已完成 PRO-I 的 1080p/30fps 短任务验证；4K/60fps 等具体组合的编码性能与真实播放效果尚未实测。

## 拍摄界面与横竖屏

主界面使用深色取景布局、琥珀色圆形快门和拍照/定时/延时模式切换。竖屏操作区位于底部；横屏位于右侧。取景、任务状态与进度留在主界面，所有配置通过快门下方的设置入口进入拍摄设置、视频输出或镜头与设备能力。结果入口提供本次照片数量、成片信息和导出功能。

设置自动保存在本机，退出菜单、旋转及进程重启后保留。拍摄/合成期间配置和模式锁定，仍可查看菜单；拍摄时快门变为暂停/继续，停止按钮单独显示，合成期间可取消。暂停会等待当前照片保存完毕后进入已暂停状态。

布局按实际可用宽高切换，菜单高度随屏幕变化并可滚动。方向变化由 Activity 处理而不销毁服务绑定；同一 PreviewView 持续提供预览，更新显示方向。拍摄期间冻结照片输出方向，保持序列一致，空闲时随屏幕方向更新。预览使用 FIT_CENTER 保留完整画面，可能有黑边。

Android 14 模拟器交互与截图证据见 [docs/ui-validation.md](docs/ui-validation.md)。模拟器取景图案是模拟相机输出；它不代表 PRO-I 的实际画质或相机方向行为。

## 停止后自动保存

0.5.3 延时模式固定自动合成，正常结束或点击停止后，至少两张照片时自动生成视频并保存到手机相册的 `Movies/XperiaTimelapse` 文件夹。无需手动选择导出位置或应用。视频写入 MediaStore 的待发布条目，完整复制并核对 SHA-256 后才向相册发布；发布成功并记录 metadata 后才按设置清理原片。保存失败或取消时删除本次未完成条目，保留项目视频和原片。单张拍照、定时拍照保持照片输出。结果页的分享按钮只是可选分享，不参与自动保存。

## 0.5.6 相册、黑屏与指示灯

主界面的文件按钮直接打开手机相册，浏览照片和录像；本机原始项目和 ZIP 导出保留在设置菜单的项目列表。单张/定时照片完成后自动保存到 `Pictures/XperiaTimelapse`，不足两张的延时任务以照片保存；延时成片仍保存到 `Movies/XperiaTimelapse`。照片先复制到 MediaStore 待发布条目并核对 SHA-256，成功后发布，原始项目照片保留；正常延时原片不逐张写入相册，避免清理后留下重复照片。

拍摄中点取景区右上方“黑屏省电”，双击黑屏或返回键恢复。进入时隐藏系统栏、显示全黑画面、降低该窗口亮度并解除常亮；退出后恢复窗口亮度和系统栏。可按电源键熄屏继续拍摄，前台服务及 CPU 唤醒仍保持。拍摄设置提供自动黑屏开关，默认关闭；黑屏不提供管理员权限或程序强制锁屏。系统屏幕超时仍有效，但充电常亮等系统设置可能阻止自动熄屏。未测量具体省电百分比。

指示灯提示默认开启，可在拍摄设置关闭。使用静音通知灯请求，拍摄绿色、暂停黄色、合成蓝色，完成后取消。Android 和设备管理实际灯光，通知权限、勿扰模式、充电灯及其他通知都可能影响显示。没有调用闪光灯或修改系统灯设置。API 依据 [NotificationChannel.enableLights](https://developer.android.com/reference/android/app/NotificationChannel#enableLights(boolean))。

PRO-I 已验证相册跳转、照片完整复制、黑屏及实际熄屏继续拍摄，灯驱动确认绿灯/蓝灯及完成后关闭，22 帧延时完整合成并自动保存。证据见 [docs/gallery-power-validation.md](docs/gallery-power-validation.md)。

## 0.5.7 自动黑屏与防待机

开始实际拍摄 5 秒后默认自动进入黑屏，双击或返回键恢复；可从拍摄设置关闭。升级后默认启用新的 5 秒自动黑屏选项，不继承旧版默认关闭状态。正在倒计时、停止、出错或结束时不会继续触发这次延迟黑屏。

黑屏期间保持 KEEP_SCREEN_ON 和原有 CPU WakeLock，只显示低亮度黑色画面，避免系统超时自动待机；结束或退出黑屏后恢复窗口亮度与系统栏。手动按电源键或切到其他应用仍由系统处理，不强行唤醒用户主动锁定的手机。具体省电幅度未测量。

拍摄通知灯改为橙色，向系统请求常亮。PRO-I / Android 13 实际仍使用系统的 100ms 亮、6000ms 灭节奏，无法通过普通应用强制常亮；屏幕保持唤醒时通知硬件灯也可能被系统抑制。直接灯接口在此设备上返回 SecurityException，未请求特权或修改硬件节点。暂停黄色和合成蓝色保持。

真机已验证自动黑屏、97 秒无输入超过 60 秒超时仍 Awake，并完成 20 帧自动保存。详细限制与记录见 [docs/auto-black-validation.md](docs/auto-black-validation.md)。


## 0.5.8 黑屏后自动锁屏

默认在进入实际拍摄状态 5 秒后显示低亮度黑屏，30 秒后通过 Android DevicePolicyManager 真正锁屏。倒计时和相机准备时间不计入这两个时间点。锁屏时前台拍摄服务和 CPU WakeLock 继续运行，不关闭相机。双击黑屏可恢复界面；每次持续拍摄阶段只触发一次自动锁屏，恢复界面不会立即重复锁屏。

自动锁屏首次使用需要用户在系统页面启用“拍摄自动锁屏”，仅申请 force-lock，不申请清除数据或密码管理策略。拍摄设置可授权或关闭此功能；如果首次快门触发授权，只有授权成功后才开始拍摄。暂停、停止、完成、出错或进入合成阶段会取消未到期的锁屏；继续拍摄重新计时 30 秒。

5 秒至 30 秒之间保持屏幕唤醒，30 秒之后由系统锁屏。真正熄屏后硬件指示灯才可能按系统规则亮起；Android/Sony 控制闪烁方式，应用不能保证橙色常亮。构建、60 项单元测试及 lint 通过；0.5.8 已在 PRO-I 验证自动黑屏、自动锁屏、锁屏期间持续拍摄及 15 帧 H.265 自动保存，详见 [docs/auto-lock-validation.md](docs/auto-lock-validation.md)。
